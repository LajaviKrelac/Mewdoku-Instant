## How to file a request

- Use this file when you need a change in a file you do not own (spec §8.1). Do not edit that file yourself. A symbol in `sprite.ts` and a token in `tokens.css` are G2's: ask here and use a placeholder meanwhile. Running a script you do not own (`size`, `palette:check`, `npm --prefix server test -- nick`) needs no request; editing one does. A file the table does not list is the lead's: ask here first.
- One row per request: the next number (R1, R2, …), from → to (G1, G2, G4 or lead), the file and the exact change (member, key, selector or line), and why (the spec or contract section). A wire change (`src/shared/rank-api.ts` or the contract fixtures) goes to G4 with the client impact stated.
- Meanwhile, keep working against a placeholder in your own files. Never delete or narrow a member another workstream may still use before I-3.
- The receiving workstream notes what it did in its own file, under "Done for other workstreams' requests", and marks the row here **done by …**. The lead answers anything still open at I-2.
